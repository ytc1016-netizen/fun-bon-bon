# 房報爆｜三種影音風格 Demo 製作規格

存檔日期：2026-10-03
狀態：規格確認；三支正式 Demo 影片尚未完成，不得標示為已完成。

## 已確認決策
先以**同一筆示範大樓住宅案件**，製作三支 9:16 直式、各約 20–30 秒的影音 Demo。三支使用相同物件資料及介紹重點，只變更呈現風格，讓使用者比較觀感。

1. **虛擬真人版**：虛擬房仲自然出鏡，專業帶看；正式版本應有合理人物動作及自然口型同步。
2. **動漫真人版**：動漫風格人物出鏡，以較活潑的表情、節奏介紹同一住宅。
3. **語音旁白大頭貼版**：住宅空間畫面為主，搭配角落人物頭像、語音旁白與重點字幕。

## 後續房仲刊登流程
上傳物件資料與照片 → 先選擇上述三種介紹方式之一 → 生成並預覽 → 確認、送審、上架。不同風格不可改寫或虛構物件事實。

## 製作與驗收原則
- Demo 使用示範案件，明確標註非真實銷售案件。
- 不得把靜態圖片縮放、一般概念動畫或無關素材冒充完整虛擬真人影片。
- 影片完成、檔案存在且能播放後，才宣稱已交付；若上傳網站，需確認線上實際播放。
- 房報爆以短影音觀看找房為核心，不改成傳統物件列表入口。
- 房報爆的 GitHub 與 Supabase 資源獨立，不得動到 LANDX。
